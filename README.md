# GX Vue Portfolio

A collection of Vue 3 and Nuxt 3 applications showcasing modern web development practices in an [Nx](https://nx.dev/) monorepo. This repository demonstrates various frontend architectures, authentication patterns, and real-world application implementations.

## 📚 Projects

### [Cinemate](./apps/cinemate/README.md)

A movie discovery application built with Nuxt 3, showcasing API integration and dynamic content rendering.

### [Shopiverse](./apps/shopiverse/README.md)

An e-commerce platform demonstrating full-stack capabilities with Nuxt 3, authentication, and database integration.

### [Nuxt JWT](./apps/nuxt-jwt/README.md)

A demonstration of JWT-based authentication and authorization patterns in Nuxt 3 applications.

### [Fireblog](./apps/vue3-vite-fireblog/README.md)

A blogging platform built with Vue 3 and Vite, featuring Firebase integration for real-time data and authentication.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm (recommended) or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/WodenWang820118/gx.vue.git
cd gx.vue

# Install dependencies
pnpm install
```

### Running Projects

Each project can be run independently using the following commands:

```bash
# Run Cinemate
pnpm run dev:cinemate

# Run Shopiverse
pnpm run dev:shopiverse

# Run Nuxt JWT
pnpm run dev:nuxt-jwt

# Run Fireblog
pnpm run dev:fireblog
```

### Building for Production

```bash
# Build specific project
pnpm run build-cinemate
pnpm run build-shopiverse
```
